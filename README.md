## 🧪 Investigation Methodology

My security investigations follow a structured approach to ensure findings are reproducible, evidence-based, and actionable.

| Phase | Activity |
|:---:|:---|
| 01 | **Scenario & Scope** — Define the security problem and investigation objectives |
| 02 | **Environment Review** — Identify relevant Azure resources and configurations |
| 03 | **Evidence Collection** — Gather logs, events, and security configuration evidence |
| 04 | **Security Analysis** — Investigate suspicious activity and potential vulnerabilities |
| 05 | **Impact Assessment** — Evaluate security risks and potential business impact |
| 06 | **Remediation** — Recommend corrective actions and defensive improvements |
| 07 | **Documentation** — Publish findings, screenshots, and technical explanations |
